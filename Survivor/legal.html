2. Objet et acceptation

Les présentes conditions encadrent l'utilisation du jeu Last Pulse. En jouant, vous les acceptez. Si vous ne les acceptez pas, merci de ne pas utiliser le jeu.

3. Accès au jeu

Le jeu est gratuit et sans création de compte. Il fonctionne dans un navigateur récent. L'éditeur peut le modifier, le suspendre ou l'arrêter à tout moment, sans préavis ni indemnité.

4. Progression et objets virtuels

  • L'or, les coffres, les héros, les familiers, l'équipement et les niveaux sont des éléments virtuels sans aucune valeur monétaire. Ils ne peuvent être ni achetés, ni vendus, ni échangés, ni remboursés.
  • La progression est enregistrée dans votre navigateur. Elle peut être perdue si vous effacez les données du site. La sauvegarde en ligne (facultative) permet de la retrouver avec votre code secret : gardez ce code pour vous, toute personne qui le connaît peut récupérer et modifier votre progression.
  • L'équilibrage du jeu (statistiques, chances des coffres, récompenses) peut évoluer à chaque mise à jour.

5. Pseudo et classements

  • Si vous choisissez un pseudo, vos scores (pseudo, vague atteinte, XP, niveau, date) sont publiés dans les classements mondiaux, visibles par tous.
  • N'utilisez pas votre vrai nom ni de pseudo injurieux, discriminatoire, à caractère sexuel ou usurpant l'identité de quelqu'un. L'éditeur peut supprimer tout score ou pseudo inapproprié ou obtenu en trichant.

6. Publicités récompensées

  • Certaines récompenses (revivre une fois par partie, coffre bonus) peuvent être obtenues en regardant une publicité. C'est toujours facultatif : le jeu reste entièrement jouable sans.
  • La récompense n'est accordée que si la publicité est regardée jusqu'au bout. Si elle est interrompue ou indisponible, aucune récompense n'est due.
  • Le nombre de publicités récompensées peut être limité (par exemple par jour). Elles ne sont pas proposées pendant le défi du jour.
  • Les publicités actuelles sont des emplacements de démonstration : aucune régie publicitaire n'est encore utilisée. Si une régie est ajoutée, cette page sera mise à jour et votre consentement sera demandé lorsque la loi l'exige.

7. Règles de conduite

Il est interdit de :

  • tricher, modifier le jeu ou exploiter un bug pour fausser les classements ;
  • envoyer des scores de manière automatisée ou en masse ;
  • tenter de perturber, surcharger ou contourner les services en ligne du jeu.

8. Responsabilité

Le jeu est fourni « en l'état », sans garantie de fonctionnement continu ni d'absence d'erreur. Dans la limite permise par la loi, l'éditeur n'est pas responsable de la perte de progression, de scores ou d'objets virtuels, ni des interruptions de service.

9. Propriété intellectuelle

Le nom Last Pulse, le logo, les graphismes, les textes et le code du jeu appartiennent à leur auteur. Toute reproduction ou réutilisation commerciale sans autorisation est interdite. Les musiques et polices restent la propriété de leurs auteurs respectifs.

10. Données personnelles

Le jeu ne demande ni nom, ni adresse e-mail, ni mot de passe. Voici ce qui est traité :

  • Dans votre navigateur (stockage local) : progression, réglages, pseudo, meilleurs scores et code de sauvegarde. Ces données restent sur votre appareil ; vous pouvez les effacer depuis les réglages de votre navigateur ou avec « Reset progression » dans les Options.
  • Classements (Supabase) : pseudo, vague, XP, niveau et date de chaque score envoyé. Finalité : afficher les classements. Base : votre choix de jouer avec un pseudo.
  • Sauvegarde en ligne (Supabase), seulement si vous l'activez : votre progression et votre pseudo, associés à votre code secret. Finalité : retrouver votre progression sur un autre appareil.
  • Données techniques : comme pour tout site, les hébergeurs (GitHub Pages, Supabase) et Google Fonts (polices d'écriture) reçoivent votre adresse IP et des informations sur le navigateur lors du chargement, et peuvent les conserver dans leurs journaux techniques.

Aucune donnée n'est vendue. Le jeu n'utilise pas de cookies publicitaires ni de mesure d'audience à ce jour.

Conformément au RGPD, vous pouvez demander l'accès, la rectification ou la suppression de vos scores et de votre sauvegarde en ligne en écrivant à l'adresse de contact indiquée plus haut (précisez votre pseudo ou votre code de sauvegarde). Vous pouvez aussi adresser une réclamation à la CNIL (cnil.fr).

Mineurs : si vous avez moins de 15 ans, demandez l'accord d'un parent avant d'activer la sauvegarde en ligne ou de publier un score avec un pseudo.
